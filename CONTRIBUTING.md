# Contributing / 기여하기

Forks, fixes, translations, and device reports are welcome under the MIT license.

Please include the OS/Safari version, website URL, outer/inner display, left/right Split View placement, enabled options, and expected versus actual behavior. Remove private information from any screenshots or logs before posting them.

For code changes, explain why the change is needed and how it was checked. State whether you tested it on a physical device, in a simulator, or only in a DOM test. Avoid treating a wider `body` measurement as proof that Safari actually paints behind its controls.

포크, 수정, 번역과 기기별 동작 제보를 환영합니다. OS·Safari 버전, 사이트 주소, 외부·내부 화면, 분할 화면의 좌우 위치, 옵션 상태, 기대한 화면과 실제 화면을 알려주세요. 공개하기 전에 개인정보를 제거해 주세요.

코드를 수정했다면 이유와 확인 방법을 적어주세요. 실제 기기, 시뮬레이터, DOM 테스트 중 어디에서 확인했는지 구별해야 합니다. 본문 너비가 커졌다는 측정값만으로 Safari 컨트롤 뒤에 실제로 표시된다고 판단하지 않습니다.
